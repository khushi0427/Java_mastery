Welcome

This is the application shell for Java Full-Stack Mastery. Layout, navigation, and theming are in place; the content that fills them arrives in later phases.

What exists right now

Phase 2 built the shell only: the top bar, the sidebar and its mobile drawer, light and dark themes, and hash-based view switching. No learning content, no module data, no progress tracking, and no code execution exist yet.

The authoritative status is docs/PROJECT_STATE.md. The filesystem outranks any claim made in the interface.

Next: Phase 3

Dashboard data, the 43-module metadata layer, and the search foundation.

Then: Phase 5

Code execution — an online adapter with a local javac fallback that always works.
